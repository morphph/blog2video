# Script Quality Evaluation Rubric

## 用途

本 rubric 用于评估 Blog2Video pipeline 产出的口播稿质量。
评估者（Claude）对照 10 个维度打分，每个维度 1-5 分，满分 50 分。

## 评估输入

评估时需要以下文件：
1. `source_blog.md` — 原始博客
2. `video_N_script.md` — 待评估的口播稿
3. `example2.md`（如有）— benchmark 参考稿（不是用来机械模仿，是用来标定质量上限）

## 10 个评估维度

### 1. Hook 抓力 (Hook Grip) — 权重 ×2

评估前 2-4 句的抓人能力。

| 分数 | 标准 |
|------|------|
| 5 | 前 2 句有具体名词/数字 + 让观众觉得"跟我有关" + 留下未闭合问题。观众不可能划走 |
| 4 | 前 2 句有具体素材，但"跟我有关"或"悬念"稍弱 |
| 3 | 开头有一定吸引力但不够具体，或使用了泛泛提问 |
| 2 | 开头是概念定义、行业背景、或"今天我们来聊" |
| 1 | 开头完全没有信息增量，观众秒划 |

检查项：
- [ ] 前 2 句是否有具体名词/数字？
- [ ] 是否避免了禁止项（定义术语、行业背景、泛泛提问）？
- [ ] 是否制造了未闭合的信息缺口？

### 2. 观点密度 (Insight Density)

评估全片判断句/压缩结论句的数量和质量。

| 分数 | 标准 |
|------|------|
| 5 | 5+ 条高质量判断句，每条有证据支撑，覆盖核心论点 |
| 4 | 3-4 条判断句，大部分有证据支撑 |
| 3 | 2 条判断句，或判断句存在但缺乏证据 |
| 2 | 1 条判断句，且比较浅表 |
| 1 | 没有判断句，全是描述和叙述 |

判断句的定义：包含对比/翻转/因果的压缩结论。
- ✅ "差的不是智能，是智能周围的系统"
- ❌ "他们使用了三个Agent的架构"（这是描述，不是判断）

### 3. 机制解释深度 (Mechanism Depth)

评估是否解释了"为什么有效"而不仅仅是"是什么"。

| 分数 | 标准 |
|------|------|
| 5 | 每个核心机制都解释了失败模式 + 为什么直觉方案不够，且解释清晰有力 |
| 4 | 大部分机制有双层解释，个别只说了"是什么" |
| 3 | 解释了失败模式，但没有讨论直觉替代方案 |
| 2 | 只描述了机制"是什么"，没有解释"为什么" |
| 1 | 列举概念名称，几乎没有机制解释 |

### 4. 证据具体性 (Evidence Specificity)

评估引用的证据是否具体、有力。

| 分数 | 标准 |
|------|------|
| 5 | 5+ 个具体证据（数字、产品名、bug 场景），无一是编造的 |
| 4 | 3-4 个具体证据，均来自原文 |
| 3 | 2 个具体证据，或有些证据不够具体 |
| 2 | 1 个具体证据，其余是泛泛描述 |
| 1 | 几乎没有具体证据，全靠比喻和抽象描述 |

证据类型优先级：具体事实 > 数字 > bug场景 > 引用 > 类比

### 5. Non-obvious 洞察 (Non-obvious Insights)

评估是否包含需要"想一下才意识到"的认知。

| 分数 | 标准 |
|------|------|
| 5 | 2+ 个真正 non-obvious 的洞察，观众听到会想"等一下，为什么？" |
| 4 | 1 个高质量 non-obvious 洞察 + 1 个一般的 |
| 3 | 1 个 non-obvious 洞察 |
| 2 | 有一些深度但不算真正 non-obvious |
| 1 | 所有内容从标题就能猜到 |

### 6. Tradeoff 诚实度 (Tradeoff Honesty)

评估是否包含代价、局限、适用边界。

| 分数 | 标准 |
|------|------|
| 5 | 2+ 个具体 tradeoff，有数据或场景支撑，不是敷衍的"当然也有不足" |
| 4 | 1 个实质性 tradeoff + 1 个较浅的提及 |
| 3 | 1 个实质性 tradeoff |
| 2 | 提到了局限但非常笼统（"也有一些不足"） |
| 1 | 全程只讲爽点，零 tradeoff |

### 7. 情绪曲线 (Emotional Arc)

评估视频是否有起伏，而不是平铺直叙。

| 分数 | 标准 |
|------|------|
| 5 | 有清晰的好奇→意外→恍然大悟→赋能的曲线，至少 1 个"哇"时刻 |
| 4 | 有明显的情绪起伏，但某个节点（如"哇"时刻）不够强 |
| 3 | 有一些起伏但整体偏平 |
| 2 | 基本是平铺讲解，只有开头和结尾有变化 |
| 1 | 完全平铺直叙，像教科书 |

### 8. 表达自然度 (Naturalness)

评估口播稿是否适合口头表达、是否自然流畅。

| 分数 | 标准 |
|------|------|
| 5 | 全文自然流畅，像一个懂行的朋友在聊天，无书面化长句 |
| 4 | 大部分自然，偶有 1-2 处书面化表达 |
| 3 | 整体可以但有明显的"翻译腔"或"教科书腔" |
| 2 | 多处书面化、正式用语，像在读论文 |
| 1 | 完全不像口播，像学术报告 |

### 9. 结构完整性 (Structure Completeness)

评估 Slide 结构、品牌植入、时间分配是否合理。

| 分数 | 标准 |
|------|------|
| 5 | Slide 标记完整，品牌植入位置正确，时间分配合理，TTS 友好 |
| 4 | 基本完整，有 1 处小问题 |
| 3 | 缺少 1 个必要元素（如品牌植入位置错误） |
| 2 | 多处结构问题 |
| 1 | 结构严重不完整 |

### 10. 行动力结尾 (Actionable Ending)

评估结尾是否给出了具体可执行的动作。

| 分数 | 标准 |
|------|------|
| 5 | 动词开头、5分钟内可开始执行、针对目标观众的具体动作 |
| 4 | 有具体动作，但可执行性或针对性稍弱 |
| 3 | 有动作但比较泛（"试试看"） |
| 2 | 只有抽象原则（"记住三个要点"） |
| 1 | 没有行动号召 |

## 评分计算

- Hook 抓力（×2）+ 其他 9 个维度（×1）= 总分（满分 55）
- Hook 权重 ×2 是因为它直接决定完播率

## 评分等级

| 总分 | 等级 | 含义 |
|------|------|------|
| 45-55 | A | 接近或达到 benchmark 水平 |
| 38-44 | B | 明显优于旧链路，可上线 |
| 30-37 | C | 有改善但仍有明显短板 |
| 22-29 | D | 与旧链路差不多 |
| <22 | F | 低于旧链路 |

## 评估输出格式

```markdown
# Script Evaluation: [video_name]

## 逐维度评分

| 维度 | 分数 | 权重 | 加权分 | 关键证据 |
|------|------|------|--------|----------|
| Hook 抓力 | X/5 | ×2 | X | [引用脚本前2句] |
| 观点密度 | X/5 | ×1 | X | [列出找到的判断句数量] |
| 机制解释深度 | X/5 | ×1 | X | [是否有双层解释] |
| 证据具体性 | X/5 | ×1 | X | [列出具体证据数量] |
| Non-obvious 洞察 | X/5 | ×1 | X | [引用最好的1条] |
| Tradeoff 诚实度 | X/5 | ×1 | X | [引用 tradeoff] |
| 情绪曲线 | X/5 | ×1 | X | ["哇"时刻在哪] |
| 表达自然度 | X/5 | ×1 | X | [最不自然的1句] |
| 结构完整性 | X/5 | ×1 | X | [缺失的元素] |
| 行动力结尾 | X/5 | ×1 | X | [引用结尾动作] |

**总分：XX/55 — 等级 X**

## 最差的 3 个维度

1. [维度名] (X/5)：[具体问题 + 改进建议]
2. [维度名] (X/5)：[具体问题 + 改进建议]
3. [维度名] (X/5)：[具体问题 + 改进建议]

## 与 benchmark 对比（如有 example2.md）

- 比 benchmark 更好的地方：[...]
- 比 benchmark 更差的地方：[...]
- 整体判断：新链路产出 [优于/持平/劣于] 旧链路
```

## 使用方法

### 评估单个脚本
```
请用 eval-rubric.md 评估 video_1_script.md 的质量。参考 source_blog.md 和 example2.md。
```

### A/B 对比
```
请用 eval-rubric.md 分别评估 旧版 video_1_script.md 和 新版 video_1_script.md，然后对比。
```

### 迭代改进
```
根据评估结果中"最差的3个维度"，修改 prompt 后重新生成，然后再评估。
```
