现在开跑。
最多 300 个子 Agent 分波次并行点火。
第一波先处理那些完全独立、谁也不靠的子任务。
结果一落地，协调器立刻拉起下一波，去做那些依赖前面结果的任务，一直到整张依赖图跑完。
这里藏着真正的结构性技巧：每个子 Agent 都在自己独立的、有边界的上下文窗口里工作。
为什么这很重要？
因为一个 Agent 单独干长任务，会越干越蠢。
不是它笨。
是它的上下文窗口会被自己填满，填到溢出，然后开始有损压缩。
从那一刻起，它后面每一步推理都更差。
而 Swarm 给每个子任务都配了独立的、划好范围的上下文，最后只把结构化的结果回传给协调器。
所以那些会逼疯单个 Agent 的任务，它扛得住。
为什么敢这么浪费？
因为它够便宜。
输入每百万 token 零点九五美元，输出四美元，重复内容命中缓存只要一毛六。
便宜带来的不是省钱。
便宜真正改变的，是你愿意尝试什么。
你能负担得起把第一次结果直接扔掉、重跑一遍——这本身就是一种新能力。
