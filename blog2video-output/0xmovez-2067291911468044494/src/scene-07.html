现在到了整套循环里,唯一不属于 Kimi 的那一拍。
Swarm 有个已知的毛病：除非你明确要求它去核查，它会产出一堆听起来很自信、但引用严重不足的论断。
而且独立的子 Agent 之间，有时候会自相矛盾。
「看起来做完了」和「它是对的」，是两个星球的事。
这里就该 Opus 4.8 上场了。
它的角色不是再生成什么更漂亮的东西——它的唯一职责，是证伪，不是夸奖。
Anthropic 说，它放过自己代码里缺陷的概率，比上一代低了大约四倍。
它也是第一个在「不加批判地报告有问题的结果」这件事上拿到零分的 Claude。
这个零分,是好事。
你花高价 token，不是用来生成的。
你是用它，去抓那个会在下一步被永久存进 Skill 的隐藏缺陷。
为什么非得是另一个模型来把关？
因为没有任何一个模型能全面碾压。
就拿一项 Agent 能力的核查基准来说，四个模型各有胜负，谁也没赢者通吃。
便宜的并行量，只有在有个可信的东西在检查它的时候，才是超能力。
