# Video 1: Manus半年重写5次，凭什么越来越强？

[SLIDE 1: cover] (0:00 - 0:35)

Manus半年改了五次架构。模型没换，每次都变强。

你是不是也遇到过这种情况？花了大价钱用最好的模型，Agent还是不靠谱。任务做到一半崩掉，工具乱调一通。你以为换个更强的模型就好了？但Manus用同一个模型，光靠改架构就做到了。秘密到底在哪？

这里是精读AI。AI 世界很吵，每期帮你从全球顶级 AI 团队的一手文献里，读透一篇最值得读的。今天我们精读的是 Aakash Gupta 的文章。

他提出了一个颠覆行业认知的判断：2026年AI竞争的护城河，不在模型，在harness。

[SLIDE 2: principle] (0:35 - 2:20)

什么是harness？打个比方。模型是发动机，harness是整辆车。最好的发动机，没有方向盘和刹车，哪儿也去不了。

Agent harness就是包裹在模型外面的基础设施。人类审批、文件权限、工具编排、错误处理。模型只负责生成回答，剩下的事，都是harness在管。

Claude Code就是最好的例子。爆火的不是Claude模型本身，而是Claude Code。同一个模型，换了一套更好的harness，产品体验完全不同。

这说明什么？模型是通用的，harness才是差异化的来源。

[SLIDE 3: comparison_cards] (2:20 - 4:40)

你可能会说，真有这么大区别吗？三家顶级公司亲自验证了。

先看Manus。半年之内，他们把harness的架构改写了五次。注意，模型一直没换。每次改写之后，任务完成率都在提升。驱动改善的，不是更聪明的模型，而是更合理的架构。

再看LangChain。他们的Deep Research产品，一年之内改了四次架构。不是因为模型变了，是因为他们找到了更好的方式来组织工作流、管理上下文、协调子任务。

但最让人意外的是Vercel。他们的Agent原本配了一整套工具库：搜索、代码、文件、API，什么都有。结果呢？Agent反而被搞糊涂了，乱调工具，多走弯路。后来他们做了一件反直觉的事：砍掉百分之80的工具。结果响应更快，成功率更高。不是加东西让Agent变强了，是减东西。

这就像整理衣柜。东西太多反而每天出门找不到衣服，扔掉大部分后效率翻倍。

[SLIDE 4: quote] (4:40 - 5:30)

你可能会想：等下一代模型出来，这些问题不就自动解决了吗？

恰恰相反。模型越强，harness反而越重要。更强的模型能做更多事，但更多能力意味着更多的失败模式，你需要更精密的错误处理。而且强模型更贵，好的harness能把简单任务分给便宜模型，帮你省钱。生产环境要求百分之99.9的可用率，模型天生是概率性的，只有harness才能提供回退和校验。

模型的进步不会取代harness，只会让harness的价值更大。

[SLIDE 5: summary] (5:30 - 6:00)

所以，竞争格局已经变了。以前的护城河是模型质量。GPT-4、Claude、Gemini，谁模型好谁赢。但现在模型质量在趋同，几周就能训出有竞争力的模型。新护城河是harness质量。Manus花了半年，LangChain花了一年，这些需要几千个小时的工程积累，没法从Hugging Face上下载。

今天给你一个可以立刻做的事：把你的Agent最近出错的case收集起来，分个类。有多少是模型回答质量差？有多少是流程控制、错误处理、权限管理的问题？你会发现，大部分是后者。
