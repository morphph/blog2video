# Video 1: 一个人写代码太慢？让AI组团帮你干活！

[SLIDE 1: cover] (0:00 - 0:25)

你有没有想过，让好几个AI同时帮你写代码？一个搞前端、一个搞后端、一个跑测试。就像带了一个AI开发团队。Claude Code现在真的能做到了。

这里是 AI 精读。AI 世界很吵，每期帮你从全球顶级 AI 团队的一手文献里，读透一篇最值得读的。今天我们精读的是 Claude Code 官方文档中关于 Agent Teams 的最新能力。

[SLIDE 2: principle] (0:25 - 2:00)

Agent Teams 是什么？想象一个项目组。组长协调全局，组员各负责不同模块。关键是，组员之间可以直接沟通，不用事事通过组长传话。

你启动一个 Claude Code 会话当组长，让它召集几个 Teammate。每个 Teammate 是独立的 Claude 实例，有自己的 Context Window，也就是自己的工作台面。

这里有个细节很关键。Teammate 之间可以直接互相发消息。前端的 Teammate 发现接口有问题，直接找后端的商量，不用等组长转达。这才是真正的团队协作。

[SLIDE 3: comparison_cards] (2:00 - 4:00)

那跟之前的 Subagent 有什么区别？

Subagent 像外卖骑手。你下单，骑手独立完成，把结果送回来。他不会跟其他骑手商量路线。Agent Teams 呢？是真正的项目组，组员之间随时沟通，遇到问题当场讨论。

核心差异在沟通。Subagent 只能向主 Agent 汇报结果。Agent Teams 的队友可以直接互相发消息，通过共享任务列表自主协调。

Subagent 适合只需要结果的聚焦任务。Agent Teams 适合需要讨论的复杂工作。官方给了四大场景：多角度调研、模块并行开发、竞争假设调试、跨层协调。

比如让五个队友同时测试不同的 Bug 理论，互相质疑对方的假设，像科学辩论一样。这种玩法 Subagent 做不到。

但要注意，每多一个 Teammate 就像多雇一个员工，Token 成本会上升。因为每个都是独立实例，不共享上下文。简单任务用 Subagent 就够了。

[SLIDE 4: summary] (4:00 - 5:00)

总结一下。Agent Teams 是 Subagent 的升级版。当任务复杂到需要多个AI互相讨论时，它比单打独斗高效得多。但也要权衡 Token 成本。

你现在可以做一件事。看看手上的项目，有没有三个以上可以同时推进的独立模块。如果有，就值得试试 Agent Teams。
