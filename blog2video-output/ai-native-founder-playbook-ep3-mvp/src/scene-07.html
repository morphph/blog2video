为什么？
如果你没把规格和架构约束，写在 AI 读得到的地方，那它每开一个新 session，都要从零重新推导那些最底层的决定。
而每一次推导，都会悄悄飘移一点点。
最后你得到的，是一个没有连贯心智模型的代码库。
注意，坏的不是哪一块零件——每一块单独看都没问题。
坏的是，这些零件从一开始，就没有一张统一的图纸，从没被设计成能拼到一起。
更阴的是，它会很晚才暴露。
平时一切都能跑，等真实用户一上量，它就塌了。
那护栏怎么装回去？
在 Claude Code 写下第一行生产代码之前，先用 Claude 把架构定下来——要遵循哪些模式、要避开哪些依赖、有意识地接受哪些取舍。
然后把这份东西，存成一个文件，叫 CLAUDE.md。
它是你项目级的、持久的"记忆"，Agent SDK 在这个目录里跑的时候，会自动去读它。
这就是你亲手写回的第一条护栏。
