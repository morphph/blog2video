技术债这边，是同一个打法。
Claude Code 做全量架构审计，把发现喂给 Claude 排期：哪些下个版本前必须修，哪些可以等一等，哪些是现阶段可以接受的存量债。
顺手把 MVP 期只活在你脑子里的那些架构决策，落盘进 CLAUDE.md，让以后每次开工，都从共同的理解出发。
安全也一样：Claude Code 做面向 SOC 2、GDPR 这类合规框架的代码级扫描，再让 Claude 排出修复顺序，设计企业客户签单前一定会查的访问控制和审计日志。
还记得第一集立的那个 flag 吗，精益的十人独角兽？
它的机制，到这一集才真正兑现。
小团队能运转得像一家大得多的公司，不是省钱技巧，是被这个飞轮，在结构上撑起来的。
