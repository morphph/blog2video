第二种力，方向完全相反：不是挡对手进来，是抬高用户离开的成本。
用户在你的产品上跑得越久，它就嵌得越深。
他们在上面搭了自动化，训练了团队，接上了自己的数据源。
他们打磨的提示词、固化的流程、标准化的输出，全是围绕着你的产品成形的。
到这一步，换掉你，就不再是一个产品决策，而是一场全公司的运营工程。
建设动作也和第一种力完全不同：铺集成的表面积。
用 Claude Code 快速接上用户依赖的数据管道和工具；再往深一步，建好 API、webhook 这些接口，配上 SDK 开发工具包，让客户不只是使用你的产品，而是在你的产品之上，构建他们自己的东西。
这是最深的一种绑定。
