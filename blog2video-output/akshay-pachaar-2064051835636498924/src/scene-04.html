精读AI · 自我修复 AGENT
[04/10]
// WHY IT MATTERS · 为什么重要
决定 Agent 好坏的,是
harness 那层脚手架,不是模型
harness
包在裸模型外面那一层 ——
prompt · 工具 · 各种检查
同一个模型 + 更好的 harness → 结果好得多
// THE CRUX · 症结:这活儿永远干不完
升级
每升级一次模型→多一批新失败模式
加工具
每加一个工具→多一批新边界情况
复杂度
harness 变复杂的速度›快过人手工追踪追不上
为什么这件事这么重要？
因为决定 Agent 好坏的,越来越不是模型本身。
Cursor 公开聊过,他们在 Agent 外面那层 harness 上投入了多少工程。
所谓 harness,就是包在裸模型外面的那一层——prompt、工具、各种检查。
同一个模型,换上一套更好的 harness,结果好得多。
而这活儿,永远干不完。
这就是症结。
每升级一次模型,多一批新失败模式。
每加一个工具,多一批新的边界情况。
harness 越长越复杂,复杂的速度,比任何团队手工追踪和修复的速度都要快。
你一个人,追不上它。
