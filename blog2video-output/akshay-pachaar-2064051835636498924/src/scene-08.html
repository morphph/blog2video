第三个转折,关于你到底在测什么。
大多数所谓的 playground,本质是 prompt playground。
你改一句系统提示词,重跑一次模型调用,看输出变了没有。
可这回答的是个错问题。
生产环境真正要问的是:我改了这一处,整张 Agent 图会怎么反应?
差别巨大。
一个 Agent 不是一次模型调用,它是一整张图——多个步骤、多个工具、彼此牵连。
你只重跑单次 prompt,看到的是局部;你要看的,是改动顺着整张图传下去之后,整个系统的反应。
所以正确的做法,是把完整埋好点的 Agent,端到端跑一遍,盯着改动在整张 span 树上引起的连锁反应。
这才叫测试一个 Agent,而不是测试一句话。
而且还有个附带好处:这种沙箱里的测试足够安全,产品经理、领域专家、做 QA 的人都能进去调配置、试方案,完全不用碰一行 git。
