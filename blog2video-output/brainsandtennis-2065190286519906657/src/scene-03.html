我前面说的那个四倍分歧不是笑话。
当市面上最流行的几个产品，在“该配多少工具”这种最基础的问题上都能差出四倍，这本身就是一个信号——这个领域根本没有公认的原则。
大家都是各凭手感。
写这篇文章的人,花了将近一年打磨 Shortcut 这个表格 Agent。
它被广泛认为是市面上最准的表格 Agent，部署在全球四大多策略对冲基金里的三家。
在那种地方，算错一个数字代价非常高，没人会给你的成绩放水。
他们没有微软或者 Anthropic 那种铺天盖地的渠道，靠的就是一件事——这个 Agent 出错更少。
所以“怎么让 Agent 更准”，是他每天都在琢磨的问题。
