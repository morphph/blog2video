记住这一句:谁来找路
很多人把 Agent 挂在嘴边，其实脑子里是一锅粥。
这篇文章上来先做了一个特别重要的切分。
它把所有能自己动手的系统统称为 agentic 系统。
但里面分两种。
一种叫 Workflow，工作流。
就是大模型和工具，按照你事先写死在代码里的路径一步步走。
另一种才叫 Agent。
模型自己决定下一步用什么工具、怎么完成任务、走几步。
差别在哪？
Workflow 的路是你铺好的，模型只是在上面跑。
Agent 是模型自己找路。
记住这个区分，后面全靠它。
