Agent 听起来很玄。
文章却说了句大实话。
Agent 能干很复杂的活，但它的实现往往简单得出人意料。
说穿了，它就是一个大模型，拿着一组工具，根据环境给的反馈，在一个循环里转。
它怎么工作？
先从人这里拿到一个指令，或者跟人聊清楚要干什么。
任务明确了，它就自己规划、自己执行。
执行过程里最关键的一点，是每走一步都要从环境里拿到真实反馈。
工具返回了什么、代码跑出了什么结果。
靠这些真实反馈来判断自己进展如何。
卡住了或者到了检查点，它可以停下来问人。
