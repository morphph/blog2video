如果这期你只记住一件事，记住这个。
文章最后抛出了一个大多数人都忽略的胜负手。
所有人的精力都砸在打磨 prompt 上，把工具当成写死的 API，懒得管。
但 Anthropic 说，工具的定义，值得你投入和整体 prompt 一样多的心思，甚至更多。
他们造那个解决真实 GitHub issue 的 SWE-bench Agent 时，花在打磨工具上的时间，超过了打磨主 prompt。
而且有个特别反直觉的点。
该选什么工具格式，不取决于对程序员来说规不规整，而取决于模型写起来累不累。
