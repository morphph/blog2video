绕了一圈，文章把三条核心原则拍在桌上。
第一，让你的 Agent 设计保持简单。
第二，把模型的规划步骤明明白白亮出来，别藏。
第三，认认真真打磨那个 Agent 和计算机之间的接口。
这三条背后是同一个判断。
别急着造更聪明的系统，先造对的系统。
最强的 Agent，往往把最多的时间，花在怎么让模型少犯错上，而不是花在怎么让模型更聪明上。
所以如果你正准备做 Agent，这篇文章给你的可执行建议其实特别朴素。
先从最简单的 prompt 起步。
用评估去优化它。
只有当简单方案真的不够用了，才一步步加上多步的自主系统。
框架能帮你快速起步，但真到了生产环境，别舍不得把那些抽象层砍掉。
AI 世界很吵，精读一篇，胜过刷一百条。
