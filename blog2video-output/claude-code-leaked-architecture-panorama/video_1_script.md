# Video 1: 47万行代码泄漏：Claude Code只用1296行思考？

[SLIDE 1: cover] (0:00 - 0:30)

Anthropic手一抖，源码全泄漏。

59.8MB的调试文件，被直接打进了npm公开包。几个小时后，全球最强AI编程Agent的完整源码，被扒了个底朝天。

这里是精读AI。AI世界很吵，每期帮你从全球顶级AI团队的一手文献里，读透一篇最值得读的。今天我们精读的是LoreAI对Claude Code泄漏源码的深度拆解。

1902个文件，47万行TypeScript代码。你猜让模型"思考"的核心逻辑有多少行？答案可能会颠覆你对AI产品的认知。

[SLIDE 2: principle] (0:30 - 2:30)

先说结论。Claude Code的核心竞争力，不在模型本身，而在模型周围那套精密的控制系统。

这话听起来有点反直觉，对吧？大家都在卷模型能力，卷参数量，卷benchmark分数。但Claude Code的源码告诉我们一个完全不同的故事。

它最大的模块叫Query Engine，查询引擎，总共46000行代码。但真正让Claude"思考"的核心逻辑，只有大约1296行。

1296行。占总代码量的百分之0.3。

剩下那45000行在做什么？在处理流式传输、错误恢复、缓存管理、权限检查、上下文组装。全是"保障性工作"。

打个比方。你去一家米其林餐厅，主厨的菜谱可能就一页纸。但整个餐厅的运营手册有500页。采购标准、食材溯源、卫生流程、出餐动线、客诉处理，全在里面。菜谱决定了味道，但运营手册决定了你每次来吃，味道都一样好。

Claude Code就是这个逻辑。1296行是菜谱，47万行是运营手册。

[SLIDE 3: comparison_cards] (2:30 - 5:00)

那这个泄漏事件本身有多戏剧性？我们来看三个关键节点。

第一，发现。2026年3月31号凌晨4点23分，安全研究员Chaofan Shou发现Anthropic在发布Claude Code的例行npm更新时，把一个59.8MB的source map文件打包进了公开包。这相当于什么？相当于银行把金库的建筑图纸，不小心夹在了宣传册里发出去。

第二，扩散。几个小时内，源码被镜像到了数十个GitHub仓库。社区开始疯狂分析。一个叫Claw Code的开源重写项目，两个小时内拿到了5万颗GitHub Star。很可能是平台历史上增长最快的仓库。

第三，规模。泄漏的内容远超预期。1902个文件，477439行TypeScript代码，42个以上的内置工具，还有44个未发布的feature flags。甚至有人发现，内部约百分之70到90的代码是由Claude自己编写的。没错，Claude Code在很大程度上是Claude写出来的。

但最有价值的发现不是这些数字。而是源码揭示的架构设计。

Claude Code的"大脑"本质上就是一个while循环。用户输入一句话，系统组装提示词，调用模型。如果模型说"我要用某个工具"，就执行工具，把结果喂回去，继续循环。如果模型说"完成了"或者触发了预算上限，就结束。

就这么简单。最好的Agent架构不是最复杂的，而是最简单的核心加上最精密的周边。

[SLIDE 4: checklist] (5:00 - 5:40)

这件事对你有什么启发？三个信号帮你判断自己的Agent项目是否走对了方向。

信号一：你的核心逻辑和控制代码的比例是多少？如果控制代码不到百分之50，说明可靠性工程还远远不够。

信号二：你的Agent出错时，有没有自动恢复机制？Claude Code光Bash安全相关的代码就超过300KB。

信号三：你在花更多时间调模型提示词，还是在构建模型周围的护栏？前者是调味，后者才是造车。

[SLIDE 5: summary] (5:40 - 6:00)

总结一下。AI Agent的真正护城河，不是模型有多聪明，而是让模型的聪明变得可靠、安全、可控的那套工程系统。这套系统在业界有个专业名称，叫Harness。

现在就可以做一件事：打开你自己的Agent项目，算一下核心逻辑和周边控制代码的比例。这个数字会告诉你，你离生产级还有多远。
