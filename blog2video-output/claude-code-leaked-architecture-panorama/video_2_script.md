# Video 2: Claude Code三层防护拆解：300KB安全代码防住了什么？

[SLIDE 1: cover] (0:00 - 0:40)

你让AI执行一条命令，它偷偷塞了一个零宽空格。

肉眼完全看不见，但执行效果完全不同。Claude Code源码里，有23条硬编码规则，专门防这种事。

这里是精读AI。AI世界很吵，每期帮你从全球顶级AI团队的一手文献里，读透一篇最值得读的。今天我们精读的是LoreAI对Claude Code源码的深度分析。

上期我们发现，Claude Code让模型思考只用了1296行，剩下47万行全是控制系统。

这期，我们继续深挖。这47万行控制系统，到底分几层？每一层在防什么？

[SLIDE 2: principle] (0:40 - 3:10)

先说第一层，上下文管理。

你可能觉得，模型不就是把对话全塞进去就行了吗？

没那么简单。Claude的上下文窗口大约200K tokens，听着很大，但用户对话可以无限长。聊着聊着就爆了。

Claude Code的解法，是一条三级压缩流水线。

想象你在整理衣柜。第一步，把明显不穿的直接扔掉。这是微压缩，纯规则驱动，不调用模型，成本几乎为零。它会看每个工具的输出，只保留最近几条，老的清掉。但清理方式有讲究，它会判断服务端的缓存是否还在。缓存在，走精细路径。缓存过期，直接替换成占位符。光这一步，源码里就有三条执行路径。

第二步，把常穿的叠整齐放好。这是会话记忆压缩。注意，它不是做对话摘要，而是提取结构化事实。项目结构、用户偏好、任务进度，提取的是事实，不是叙事。

第三步，换季大清理。这是完整压缩，用一次独立的模型调用，把整段对话历史浓缩成一条精简消息。之前的内容从模型视野中移除，但你的聊天界面还能往回翻。

再说工具加载。Claude Code内置了42个以上的工具，但不是启动就全塞进去。核心工具开机加载，扩展工具按需加载。如果工具输出太大，系统不会粗暴截断，而是存到外部，给模型一个摘要加一个指针。

这整套设计，像不像操作系统管内存？有限资源，无限需求，靠分级策略来平衡。

[SLIDE 3: principle] (3:10 - 5:30)

第二层，安全与约束。这是整个架构里最让我震撼的部分。

Claude Code可以直接在你电脑上执行bash命令、读写文件、操作git。这个能力极其强大，但也极其危险。

它怎么管权限？四层模式。

第一层，逐一确认，每个操作都问你。第二层，半自动，常见操作放行。第三层，大部分自动。第四层，YOLO模式，全自动执行。

听到YOLO模式你可能觉得很爽，但这里有个反直觉的设计。自由度越大，安全检查反而越严格。就像领导说"你看着办吧"，不代表没人盯着你，恰恰相反，监控系统开到了最高级别。

具体怎么查？双层分类器。

第一层，Bash Classifier，纯规则匹配。像小区门口的保安看门卡，只读命令直接放行，不调模型，速度极快。

第二层，YOLO Classifier。完整的LLM-as-Judge系统，用一个独立的模型调用来审查主Agent的每个操作。而且是两阶段架构，先快速判断yes或no，只有要拦截时才进入完整推理。

也就是说，每次你点"允许执行"，背后可能已经跑了两轮安全检查。

还有23条硬编码的bash安全规则。防什么？防Zsh花括号展开、防Unicode零宽空格注入、防IFS空字节注入。这些都是真实的攻击向量，不是理论威胁。光bash安全相关的代码就超过300KB。

错误处理的原则只有一条：宁可误杀，不可放过。解析失败？拦截。API报错？拦截。默认就是不信任。

[SLIDE 4: principle] (5:30 - 7:00)

第三层，多Agent与扩展。

一个模型不够用怎么办？Claude Code的答案是Swarm架构，大约6800行代码。

结构很清晰。一个Leader，带几个Teammate。想象一个项目经理带几个独立工程师。每个工程师有自己的工作台，互不干扰，上下文严格隔离。Leader只看到它发出的指令和最终结果，中间过程一概不知。

但有一个关键机制叫Team Memory Sync。工程师发现了重要信息，会同步到共享白板上，确保Leader不会漏掉关键决定。

还有MCP协议，超过11000行代码。它做的事情很简单但很强大，把任何外部服务变成Agent可以调用的工具。数据库、API、第三方服务，全部统一成工具接口。

三层架构，每一层解决一个核心难题。第一层管模型该看什么，第二层管模型不能做什么，第三层管一个模型不够用怎么办。

[SLIDE 5: summary] (7:00 - 8:00)

回顾一下。Claude Code的47万行控制系统，本质是三层防护。

上下文压缩流水线，三级策略管住有限的窗口。双层安全分类器加23条硬编码规则，用300KB代码守住安全底线。Swarm架构加MCP协议，让多个Agent协同工作又互不干扰。

安全不是Agent的附加功能，而是架构的一部分。

给你一个可以马上做的事。给你自己的Agent加一个安全分类层。先写10条正则规则拦截明显危险操作，比如rm -rf、sudo这些。再用一个轻量LLM做二次判断。两层比一层靠谱得多。
