# Video 3: Claude Code藏了44个隐藏功能？永远在线的AI要来了

[SLIDE 1: cover] (0:00 - 0:40)

Claude Code的源码里，藏了44个你看不到的隐藏功能。

其中有一个叫KAIROS。它让AI不再等你打字，而是自己在后台每隔几秒醒来一次，整理记忆、预判你下一步要干什么。甚至在你按回车之前，它已经把结果算好了。

这里是精读AI。AI 世界很吵，每期帮你从全球顶级 AI 团队的一手文献里，读透一篇最值得读的。今天我们精读的是 LoreAI 的技术博客。

上期我们拆了Claude Code的三层防护：上下文压缩、四层安全、Swarm多Agent架构。

这期是最后一期。我们来看最刺激的部分：那44个被关掉的功能，藏着AI Agent的下一个形态。还有Anthropic内部数据里一个反直觉的真相。最后，我会给你5条可以直接带走用的Agent工程原则。

[SLIDE 2: principle] (0:40 - 2:00)

先说KAIROS。

现在所有AI工具都是被动的。你问一句，它答一句。KAIROS要彻底改变这件事。

它把Claude Code变成一个永远在线的后台守护进程。系统按固定间隔向Agent发送tick提示，Agent自己决定要不要主动做点什么。

更有意思的是，它配了一个叫Dream的记忆整理引擎。空闲的时候，自动整合和修剪记忆。

你可以这样理解：它像一个随时待命的私人助理。你在开会，它在后台帮你整理笔记、查资料、准备下一场会议要用的文件。白天主动行动，夜里整理记忆。而且有15秒阻塞预算的硬性约束，不会卡住你的工作流。

这不是"更聪明的工具"，这是从工具到同事的转变。

[SLIDE 3: principle] (2:00 - 3:20)

再说投机执行，Speculation。这可能是最有工程想象力的功能。

Claude Code回答完你的问题之后，在你还没按回车之前，系统已经在后台执行它预测你会做的下一步了。

猜对了？直接合并结果，省掉等待时间。猜错了？所有写入都在沙箱里，丢掉就行，不影响你。而且一次投机完成后，立即开始下一轮。预测、执行、预测、执行，试图始终领先你好几步。

就像外卖平台在你还没点下单的时候，已经根据你的浏览记录通知附近骑手准备了。猜对了你快十分钟拿到饭，猜错了骑手回去继续等，你完全无感。

[SLIDE 4: comparison_cards] (3:20 - 5:00)

还有几个让人意外的功能。

ULTRAPLAN，把复杂的规划任务卸载到云端容器，跑Opus 4.6，最长30分钟。和Manus的区别是：Manus把整个执行放云端，ULTRAPLAN只把规划放云端，执行还是在你本地。

Buddy，没错，一个电子宠物系统。类似Tamagotchi，有物种稀有度、闪光变体，还有Claude在首次孵化时写的灵魂描述。开发者每天在终端里待8小时，这个设计把冰冷的工具关系变成了情感连接。

还有反蒸馏防御。开启后，Claude Code会在API请求里注入虚假的工具定义。如果竞争对手录制API流量来训练自己的模型，这些假定义会污染他们的训练数据。就像在自家菜谱里故意写几道假配方，谁抄了照着做，做出来的菜是难吃的。

[SLIDE 5: quote] (5:00 - 5:40)

现在说那个反直觉的内部数据。

Anthropic内部的benchmark显示，最新的Capybara v8，虚假声明率百分之29到30。而更早的v4版本只有百分之16.7。

没错，模型越新，反而越容易说假话。

这个数据直接解释了一件事：为什么Claude Code要花47万行代码去做控制系统。因为模型本身不一定越迭代越可靠，所以你必须在模型之外，建一套独立的评估和安全机制。

另一个数据：Anthropic内部约百分之70到90的代码，由Claude自己编写。AI写AI的代码，这已经是现实了。

[SLIDE 6: checklist] (5:40 - 6:40)

最后，5条可以直接带走的Agent工程原则。

第一，核心要简单，周边要精密。Claude Code用1296行实现核心循环，47万行实现周边系统。核心逻辑就是一个while循环。

第二，上下文是最稀缺的资源。要像操作系统管理内存一样管理上下文。分层、压缩、按需加载、主动淘汰。

第三，安全是架构，不是功能。300KB安全代码、双层分类器、23条硬编码规则，安全和核心循环同级。

第四，生成和评估必须分离。让一个模型负责生成方案，另一个独立模型负责检查。考试的时候，答题的人和判分的人必须是两个人。

第五，规模化靠分工，不靠更大的窗口。任务太复杂，答案不是更大的context window，而是多个Agent分工协作。

[SLIDE 7: summary] (6:40 - 7:00)

三期下来，我们从47万行源码里拆解了Claude Code的全部架构。

最核心的一个认知是：AI Agent的下一个形态，不是更大的模型，而是永远在线、主动预判的智能伙伴。但越强大的能力，越需要可靠的控制系统。

你现在就能做的一件事：在你的Agent项目里，把生成和评估分开。让一个模型负责想方案，另一个独立模型负责检查。执行者永远不能当自己的裁判。
