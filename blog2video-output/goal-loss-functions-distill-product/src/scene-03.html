来看他挂机的时候，那一个 prompt 干了什么。
大约三十个小时。
六千三百行代码。
爬了九万两千个网页。
花了四十美元的 API 费用。
它做的事情是：把另一个产品的核心循环，整个克隆出来。
架构是从零开始反向工程的。
而且关键在最后一句：在同样的查询上，他们做出来的版本，输出比那个参考产品好了大约五十倍。
秘密只有一个词，叫 loss function development，损失函数开发。
你给 Agent 的，不再是一份"照着造"的 spec，而是一个"往这个方向优化"的目标。
有个叫 Peter Steinberger 的人说得更绝：你不该再给编程 Agent 写 prompt 了，你该设计的是那个给 Agent 写 prompt 的循环。
换句话说，spec 从终点，变成了起点。
