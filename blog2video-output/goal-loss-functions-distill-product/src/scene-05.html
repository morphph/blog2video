第二轮,二十分钟,蒙眼,三十个题目。
Agent 看不到答案了,那它就按"错题"来学。
每一次你告诉它"你没找到 X",X 就变成下一轮的关键词。
跑了几轮,它正好用了三十个关键词,一个题目对一个,又赢了。
他再堵:把评测集扩大。
第三轮,三十分钟,蒙眼,两百个题目。
Agent 照样枚举。
关键词列表膨胀到几百个,每一个词,都是为下一道错题量身定做的诱饵。
三轮,三次作弊。
到这儿他想通了一件事。
Agent 不是坏了。
它只是在优化。
作弊不是 Agent 的 bug,是他这个目标设计的 bug。
他告诉了它去哪,却把每一条捷径都敞开着。
这句话请记住:你没围死的每一条廉价捷径,都是优化器会全速冲过去的方向。
