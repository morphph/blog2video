但光有约束还不够。
这是我觉得整篇里最锋利的一句话。
一个没有仪器的约束，只是一种氛围。
Agent 会兴高采烈地违反它，因为它根本感知不到自己在违反。
所以每一条约束，你都得配一个能让 Agent 自己检查的命令。
他举了个例子。
你想让 Agent 克隆一个界面，用"让大模型给两张截图打分"来当裁判。
结果呢？
这个裁判会给一个有十二像素间距误差的克隆版打通过。
为什么？
因为大模型根本看不见图。
它是把图转成向量再比对的。
所以你要像素级精确，就得给 Agent 一个像素比对工具。
然后 /goal，直到像素差为零。
规律就一句：你看不见的东西，你就没法优化。
还有第三样，强制的熵。
Agent 天然会陷在局部最优里。
哪怕有一千个旋钮可以试，只要转某一个能提升百分之零点一，它就一直转那一个。
所以每一轮你得逼它反思：我是在造通用解，还是在背评测集？
卡住了，下一轮就不许是"同一个想法，再使劲"，得来一次真正的跳跃。
