你每次用 Claude Code，是不是都要打开终端，一句一句跟它聊？改个 Bug 聊三轮，审个代码再聊五轮。但如果我告诉你，只需要多加两个字符，它就能像一个安静的员工一样，接到任务，自己做完，把结果交回来——你今晚会不会想试试？

这里是精读AI。AI 世界很吵，每期帮你从全球顶级 AI 团队的一手文献里，读透一篇最值得读的。今天我们精读的是 Anthropic 官方文档：Run Claude Code Programmatically。

[SLIDE 2: principle] (0:30 - 2:00)

先说核心结论。Claude Code 有一个参数叫 -p，也就是 --print。加上它，整个交互式聊天界面就消失了。AI 变成了一个命令行工具。

这是什么感觉？打个比方。你常去的那家餐厅，菜品没变，厨师没换，但现在它开了外卖。你不用坐在店里一道一道点了，打个电话说"老三样"，饭就送到家门口。

-p 参数做的就是这件事。同样的 Agent 能力，同样的工具链，同样的上下文管理。但你不再需要坐在终端前面盯着它。一行命令发出去，它自己跑，跑完把结果打印出来。

这意味着什么？你可以把它塞进 shell 脚本里。可以放到 CI/CD 流水线里。可以用 cron 定时执行。Claude Code 从一个聊天对象，变成了你工具箱里的一把螺丝刀——随取随用，用完归位。

[SLIDE 3: comparison_cards] (2:00 - 3:50)

那具体能做什么？我挑四个最实用的能力说。

第一个，结构化输出。加上 --output-format 参数，你可以选三种格式：text 是纯文本，json 是标准的结构化数据，stream-json 是实时流式输出。选 json 的话，AI 返回的不是一段散文，而是你的程序能直接解析的标准格式。你甚至可以用 --json-schema 指定输出的数据结构，让 AI 严格按你的模板来。

第二个，工具白名单。--allowedTools 这个参数，让你精确控制 AI 能用哪些工具。比如你让它帮你写 commit message，就只开放 git 相关的命令。语法有个细节：Bash(git commit *) 里面，星号前面那个空格不能少，它表示前缀匹配。这样 AI 能执行 git commit -m 这类命令，但碰不到别的东西。既放手，又放心。

第三个，会话接续。用 --continue 可以接着上一次对话聊。用 --resume 加上 session ID，可以回到任意一次历史会话。就像跟同一个医生复诊，不用重新描述病史，上次到哪儿接着来。

第四个，自定义角色指令。--append-system-prompt 让你在保留 Claude Code 默认行为的基础上，追加你自己的规则。比如"所有回复用中文""只修改 src 目录下的文件"。

[SLIDE 4: checklist] (3:50 - 4:30)

说了这么多，你今晚就能用起来。检查清单：

确认你已经安装了 Claude Code CLI。

打开终端，输入 claude -p 加上你的提示词，跑通第一次调用。

试试 --output-format json，看看结构化输出是什么样。

给你的日常任务写一个 shell 脚本，比如每天自动审查新的 PR。

用 --allowedTools 锁定权限，确保脚本在无人值守时也安全。
