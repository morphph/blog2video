# Stanford 4 个 prompt 把 Claude 变 PhD？

## Hook

Stanford 两年前就把一套研究方法论摆在桌面上，论文有了，代码开源了，免费在线 demo 也挂着。这套东西在峰值评测里，比当时最强的研究方法多出百分之二十五的组织度。但今天打开 Claude 用它的人，几乎没有。Nav Toor 把整套方法压成了四段可粘贴的 prompt，今天我带你把它拆开。我不打算念 prompt 模板，我们只聊一件事——为什么是这四步，少一步它就塌掉。

## 你正在用搜索框的方式用 Claude

先承认一件让人不舒服的事。大多数人用 Claude，本质上就是把它当搜索框。问一句，拿一个答案，关掉标签页。

这不是 Claude 不行。是你的提问方式，决定了它只能回这个层级。

当你问"告诉我关于 X 的情况"，模型给你的，永远是多数派观点。是这个领域里被说得最多、引用率最高、最不会得罪人的那个框架。也就是表面。

但你想要的，从来不是表面。一个每天在地里干活的实践者看到的 X，和一个研究了十年的学者看到的 X，是两件不同的东西。再加上一个怀疑这套主流叙事根本就是错的人、一个跟着钱走的经济学家、一个见过类似剧本的历史学家——你会发现，同一个话题，被五个人看，能炸开五个完全不同的截面。

所有真正值钱的洞察，都活在这五个截面对撞出来的缝里。

## STORM 是什么，以及它真正证明了什么

这套方法论有个名字，叫 STORM。Stanford 的 OVAL 实验室在 2024 年 NAACL 会议上正式发表。全称很长——通过检索和多视角提问做主题大纲合成。

但你不用记全称。记住一件事就够了。

STORM 论文里给出了一个被同行评审过的硬数字。用多视角方法生成的文章，比当时最强的对照方法，组织度高百分之二十五，覆盖广度高百分之十。

这两个数字非常关键。它不是营销话术，是学术评测。它在说——多视角提问不是"听起来高级一点"，是在统计意义上，真的能把那些单 prompt 永远抓不到的盲点捞回来。

而 STORM 的真正突破，不是它的代码，也不是它的 demo 网站。是它把博士生做研究的那套思考方法，拆成了四个可以复制粘贴的步骤。

代码你不用装，demo 你不用打开。这套思维方式本身，才是你能搬走的东西。

## 第一步：五个人格不是花活，是强制跳出均值

第一个 prompt 做一件事——让 Claude 同时扮演五个人。

实践者、学者、怀疑论者、经济学家、历史学家。

这个 cast 是固定的，每一个都被分配了一个其他四个看不到的角度。实践者告诉你学者忽略的现实细节。学者告诉你同行评审证据真正怎么说。怀疑论者攻击主流，问那些支持者刻意回避的反证。经济学家追问谁从这个叙事里赚到了钱。历史学家把当下的事件，拉回到曾经发生过的相似剧本里去对照。

你让模型一次产出这五个人的核心立场、最强证据、还有"只有这个视角才会告诉你的那句话"。

六十秒。你得到的是单 prompt 一辈子都给不出的截面差。

这是这套方法的入口。但它只是入口，不是答案。

## 第二步：矛盾图——大多数人跳过的那一步

如果你只走到第一步，把五个人格的输出拿到手就收工，你做的事和把五个搜索结果拼到一起没区别。

真正的分水岭是第二步。让 Claude 把这五个声音里互相打架的地方画出来。

哪两个视角直接矛盾？具体冲突在哪句话上？哪个视角的证据最强，哪个最弱，为什么？如果只能回答一个问题来解开最大的那个矛盾，那个问题是什么？所有五个视角都同意的是什么——这部分大概率为真，因为连对立面都在确认。最后，五个视角里都没人提到的是什么——这是整个领域的盲点，往往是你最值钱的发现。

原文有一句话我特别想直接念给你听：如果所有人都同意，它大概率是真的；如果所有人都没碰，你刚找到了整个领域的缺口。

大多数人跳过这一步。这是表面理解和真正专业之间的那条线。

跨过去，你就拿到了五分钟前还没人帮你做过的对撞分析。

## 第三步：综合——一个博士生 48 小时的活

到这里你手上有两份原料——五个截面，和它们之间的冲突地图。第三个 prompt 把这两份原料烧成一份给 CEO 看的简报。

它要求 Claude 一次给你五样东西。

一段六十秒能讲清的高层摘要，但要带 nuance，不是新闻头条那种平面化。然后是五条最重要的发现，按可靠度排序，每一条都要标注哪些视角支持、哪些视角挑战。

再然后是一条隐藏连接——只有把五个视角并排放在一起才会浮现的那条非显然的关联。再然后是一条针对你具体角色的可执行建议，要求够具体。最后是一个前沿问题，如果有一天它被回答了，会改变所有人对这个话题的理解。

注意这份简报里每一项的设计。它不是把素材堆给你，它在强迫综合发生。

一个博士生手工做出这份东西，要四十八小时。你刚才花了九十秒。

## 第四步：自我同行评审——不是反思，是补 Stanford 自己承认的 bug

讲到这里，如果故事就停在这——四个步骤里只剩第四步还没讲——你可能会想，最后一步无非是"让 AI 自我反思一下"，老套路。

但这个 prompt 真正的设计含义，比"反思"狠得多。

Stanford 团队在自己的论文里，亲自标注了 STORM 的两个已知失败模式。一个叫信源偏倚——模型在采样视角的时候，会不自觉地多采它训练分布里更熟悉的那一类声源。一个叫事实张冠李戴——模型会把 A 视角里的事实，误装到 B 视角的论证里。

这两个 bug 不是猜的，是 Stanford 自己在 limitations 章节写明的。

第四个 prompt 就是精确对着这两个失败模式打的补丁。它强制 Claude 给五条核心发现打可靠度分、找出自己最不自信的那一条、做偏倚检查指出哪个视角在综合里被过度代表、追问有没有一个第六视角被漏掉、最后给整份简报打一个 Stanford 教授会打的分。

这是把别人论文里 limitations 章节的措辞，直接翻译成 prompt 设计的工程化案例。

它不是锦上添花。它是这套方法之所以能在你的桌面上 work，而不是变成又一个被高估的 ChatGPT trick 的根本原因。

## 代价：五个人格本身也是一种偏倚

讲到这里我得停下来说一句不那么爽的话。

这套方法不是万能的。

实践者、学者、怀疑论者、经济学家、历史学家——这个固定 cast 本身就是一种偏倚。监管者的声音在哪？终端用户的声音在哪？被这个议题影响、但完全没机会发声的弱势群体在哪？

这就是为什么第四个 prompt 里有那一道题——是否还有一个第六视角被漏掉了，足以改变结论？作者自己心里清楚这个 cast 不全。

还有一个边界要承认。这套四步流程，只在有争议、有多方利益相关者的话题上回报最高。商业决策、面试调研、投资判断、谈判准备、演讲设计——这些场景才配得上跑完整套。你查一个 API 函数签名也跑五视角加矛盾图加同行评审，那是杀鸡用牛刀。

最后一个隐藏依赖。整套方法的天花板，由第一步的输出质量定死。如果 Claude 在第一步把五个人格写成了五个换皮的多数派——比如怀疑论者写得也很主流——那后面三步就找不到真矛盾，整套流程会塌缩回单 prompt 的均值回归。

你需要在第一步的输出上，肉眼盯一下——这五个声音真的不一样吗？还是其实长得很像？

## Synthesis

把整篇文章拉远了看，你会发现它真正在讲的不是一个 prompt 模板。

它在讲一件认知套利的事。

Stanford 的论文在 2024 年就发表了，同行评审做完了，代码丢在 GitHub 上挂 MIT 协议，免费 demo 现在就在网上开着。这套东西的所有可得性条件，全部齐备。

但几乎没人用。

可得性齐全 + 扩散为零，这个组合本身就是一条信号。它告诉你扩散的瓶颈从来不是技术，是认知摩擦力——绝大多数人，连"我可以用五个视角同时看同一件事"这种思考方式都没习惯。

而正是这个摩擦力，给了今天看到这条视频的你一个十八个月的窗口。

十八个月之后，这类工作流会被烧进每一个 AI 工具里，变成默认。那时候这条边消失。

而单 prompt 永远只能给你多数派的答案，所有值得做的研究，结论都藏在少数派的反对意见里。

## Closing

如果你今天只能记住一件事，请记住——你不需要五分钟，先用一分钟。

挑一个你正在卡壳的话题。不是学一个新词，是你这周真的要做决定、要写、要 pitch 的那一件事。打开 Claude，只跑第一个 prompt。让五个人格各说两句。

光是这一步，你就会感觉到，平时你拿到的，确实只是其中一个声音。

剩下三步，跑完整再花四分钟。然后再来对照你之前对这件事的判断。

AI 世界很吵，精读一篇，胜过刷一百条。我们下期再见。
