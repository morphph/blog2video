讲到这里我得停下来说一句不那么爽的话。
这套方法不是万能的。
实践者、学者、怀疑论者、经济学家、历史学家——这个固定 cast 本身就是一种偏倚。
监管者的声音在哪？
终端用户的声音在哪？
被这个议题影响、但完全没机会发声的弱势群体在哪？
这就是为什么第四个 prompt 里有那一道题——是否还有一个第六视角被漏掉了，足以改变结论？
作者自己心里清楚这个 cast 不全。
还有一个边界要承认。
这套四步流程，只在有争议、有多方利益相关者的话题上回报最高。
商业决策、面试调研、投资判断、谈判准备、演讲设计——这些场景才配得上跑完整套。
你查一个 API 函数签名也跑五视角加矛盾图加同行评审，那是杀鸡用牛刀。
最后一个隐藏依赖。
整套方法的天花板，由第一步的输出质量定死。
如果 Claude 在第一步把五个人格写成了五个换皮的多数派——比如怀疑论者写得也很主流——那后面三步就找不到真矛盾，整套流程会塌缩回单 prompt 的均值回归。
你需要在第一步的输出上，肉眼盯一下——这五个声音真的不一样吗？
还是其实长得很像？
