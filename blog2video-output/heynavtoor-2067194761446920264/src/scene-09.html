把整篇文章拉远了看,你会发现它真正在讲的不是一个 prompt 模板。
它在讲一件认知套利的事。
Stanford 的论文在 2024 年就发表了,同行评审做完了,代码丢在 GitHub 上挂 MIT 协议,免费 demo 现在就在网上开着。
这套东西的所有可得性条件,全部齐备。
但几乎没人用。
可得性齐全 + 扩散为零,这个组合本身就是一条信号。
它告诉你扩散的瓶颈从来不是技术,是认知摩擦力——绝大多数人,连"我可以用五个视角同时看同一件事"这种思考方式都没习惯。
而正是这个摩擦力,给了今天看到这条视频的你一个十八个月的窗口。
十八个月之后,这类工作流会被烧进每一个 AI 工具里,变成默认。
那时候这条边消失。
而单 prompt 永远只能给你多数派的答案,所有值得做的研究,结论都藏在少数派的反对意见里。
