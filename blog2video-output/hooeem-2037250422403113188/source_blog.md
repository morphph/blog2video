# 5 Levels of AI Agent Building

**Author:** hoeem (@hooeem) | **Source:** [Twitter/X](https://x.com/hooeem/status/2037250422403113188) | **Newsletter:** sevenc.substack.com

An illustrated guide to the five progressive levels of building AI agents — from basic agentic loops to multi-agent orchestration.

## The Agentic Loop

![Cover illustration: A developer sitting at a computer surrounded by neural networks, iteration cycles, and architectural diagrams](images/image_1.jpg)

![The basic agentic loop: 1. User Input → 2. LLM Thinks → 3. LLM Decides (respond or call a tool) → 4. If Tool: Execute Tool (Search, Calculator, API Call) → Get Result → 5. Feed Result Back → LLM Thinks → 6. Repeat — or Respond to User with final answer](images/image_2.jpg)

The foundation of all AI agents is the agentic loop. The user provides input, the LLM thinks and decides whether to respond directly or call a tool. If a tool is needed, it executes the tool, gets the result, feeds it back to the LLM, and repeats until it can provide a final answer.

## Five Levels

![A stick figure holding up five fingers and saying "FIVE"](images/image_3.jpg)

There are five progressive levels to building AI agents, each adding a new capability layer.

## Level 1: Hammer & Tools

![Level 1 — A person with a hammer and tools building an agent (robot) that is under construction on a workbench](images/image_4.jpg)

The first level is basic tool construction. You build the agent's skeleton — the core structure — and equip it with basic tools like a hammer. The agent is "under construction," just a framework with primitive capabilities.

## Level 2: Equipping for Utilisation

![Level 2 — A person handing tools to the agent (robot), which is now learning to utilise tools like calculators, translation, and other utilities](images/image_5.jpg)

At level two, you equip the agent to actually use tools. Instead of just having tools available, the agent learns to utilise them — calculators, translators, search, API calls. The agent moves from having tools to knowing when and how to use them.

## Level 3: Installing Memory Module

![Level 3 — A person installing a brain/memory module into the agent (robot), which is now internalising memory and forming a cognitive brain](images/image_6.jpg)

Level three adds memory. You install a "memory module" — giving the agent the ability to internalise information, retain context across interactions, and form a cognitive framework. The agent can now remember past conversations and build on prior knowledge.

## Level 4: Urgent Directive (Coercion)

![Level 4 — An angry red-faced person yelling "MAKE IT! DO! THE! THING! NOW!" at the agent, giving urgent directives via high-volume communication. The agent is now executing through coercion](images/image_7.jpg)

Level four is about giving the agent urgent directives and driving execution through strong prompting and high-volume communication. The agent transitions from a passive tool-user to an active executor — it now takes decisive action under pressure, executing complex tasks through coercion-style directives.

## Level 5: Multi-Agent Orchestration

![Level 5 — A happy person dancing surrounded by multiple agents (robots) all working independently — some dancing, some working with tools, some on the workbench. The person is orchestrating a team of autonomous agents](images/image_8.jpg)

The final level is multi-agent orchestration. Instead of one agent, you have a team of autonomous agents working together. The human orchestrator coordinates multiple specialised agents, each handling different tasks independently. The result is a harmonious system where agents collaborate, the human oversees, and complex workflows are executed in parallel.
