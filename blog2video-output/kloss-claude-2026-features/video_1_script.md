[SLIDE 2: principle] (0:10 - 0:35)

这里是精读AI。AI 世界很吵，每期帮你从全球顶级 AI 团队的一手文献里，读透一篇最值得读的。今天我们精读的是一篇关于 Claude 2026 全部更新的深度指南。

Anthropic 在2026年一口气更新了三个模型。信息量很大，我先帮你把最核心的变化提炼出来：所有模型的 Context Window 统一拉到了100万 token，而且标准定价，不加钱。

[SLIDE 3: comparison_cards] (0:35 - 1:25)

先说旗舰，Opus 4.6。你可以把它想象成一个能连续工作14个半小时不休息的高级工程师。100万 token 上下文，最大输出12万8千 token，定价每百万输入5美元、输出25美元。

在 MRCR v2 这个长文本基准测试上，它拿了百分之七十八点三。什么概念？就是你把一整本技术书塞给它，它能精准定位到某一段的某一句话。

适合什么场景？复杂代码重构、深度研究、跨文件分析。但注意，如果你一天跑好几次，账单可能飙到50到100美元。它是手术刀，不是菜刀，别拿来切土豆。

[SLIDE 4: comparison_cards] (1:25 - 2:10)

再说 Sonnet 4.6，这才是大多数人的主力。同样100万上下文，最大输出6万4千 token，定价3美元和15美元。速度比上一代快百分之三十到五十。

关键数据：百分之七十的用户偏好它超过上一代 Sonnet 4.5，百分之五十九的人觉得它甚至比老旗舰 Opus 4.5 还好用。也就是说，一个中端型号，干掉了上一代的顶配。

它现在是免费版和 Pro 版的默认模型。日常编码、写作、Agent 工作流，首选它。

[SLIDE 5: principle] (2:10 - 2:50)

然后是 Haiku 4.5，走量型选手。速度快、价格低，适合高并发批处理场景。

但这里有个关键风险你必须知道：Haiku 4.5 没有 prompt injection 防护。什么意思？如果你的应用会接收用户输入，恶意指令可以直接穿透。所以它只适合你完全控制输入的内部流水线，绝对不要拿它做面向用户的产品。

[SLIDE 6: principle] (2:50 - 3:35)

现在说今天最反直觉的部分：100万 token 标准定价。

以前用 Opus 超过20万 token，价格会跳到每百万输入10美元、输出37美元5。现在不管你用20万还是100万，价格一样。

100万 token 是什么概念？大约75万个英文单词，或者一次性处理600张图片和 PDF 页面，这比之前的100张上限翻了6倍。

[SLIDE 7: quote] (3:35 - 4:10)

回到开头那个案例。一家公司把 Context Window 从20万提到50万，总 token 消耗反而降低了。原因很简单：以前上下文不够，模型要反复重读之前的内容，每次重读都在烧 token。上下文够大之后，一次读完，不用回头，总消耗自然就降了。

这就像搬家时用小箱子要跑十趟，换个大卡车一趟搞定，油费反而更少。

[SLIDE 8: checklist] (4:10 - 4:45)

最后给你三个可以今天就执行的动作。第一，把你现有项目的上下文提高到50万 token 以上，跑一周对比总消耗，大概率会降。第二，日常任务全部切到 Sonnet 4.6，性价比最高。第三，只在复杂分析和大规模重构时切 Opus，用完就切回来。
