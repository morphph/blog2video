[SLIDE 1: cover] (0:00 - 0:30)

每次打开一个新的 Claude 对话，你是不是又要从头解释一遍自己是谁、在做什么项目？有个叫 Vin 的人说，他只需要打一个命令，AI 就能瞬间加载他的整个人生。项目描述、播客上下文、个人工作流，全部到位，一个字都不用解释。

这里是精读AI。AI 世界很吵，每期帮你从全球顶级 AI 团队的一手文献里，读透一篇最值得读的。今天我们精读的是一期播客访谈——Internet Vin 分享他如何用 Obsidian 加 Claude Code 管理整个人生。

[SLIDE 2: principle] (0:30 - 2:15)

先说结论：这套系统的价值，不是 AI 能读你的文件。

你可能会说，文件谁不会读？把一个 markdown 丢给 Claude，它当然能读。但问题是，你有几十个文件。项目描述一个，会议记录一个，日记一个，每个文件单独看都没什么特别的。

打个比方。一堆散落的照片，你翻来翻去也就是零碎的回忆。但如果有人帮你按时间线、按人物关系整理成一本相册，你一翻就能看到完整的故事。

Obsidian 做的就是这件事。它不是一个普通的笔记本，它是一个 Vault——知识库。每个文件之间可以用双括号互相链接。你在日记里写了"今天和 Greg 录播客"，这句话就会自动连回你的 Greg Eisenberg 笔记。写得越多，链接越密，最终形成一张知识图谱。

关键来了。Obsidian 最近发布了一个 CLI 工具。有了它，Claude Code 不仅能读取 Vault 里的每个文件，还能看到文件之间那些隐形的连线——谁引用了谁，谁和谁相关。

这就像给 AI 装了一副特殊的眼镜。之前它只能一页一页翻你的笔记本。现在它能看到整张关系网。

[SLIDE 3: comparison_cards] (2:15 - 4:15)

那这张关系网到底能带来什么？我们拆成三层来看。

第一层，消灭重复解释。Vin 造了一个 /context 命令。一敲回车，Claude Code 自动读取他的 README、项目描述、播客上下文、个人工作流——全部加载完毕。每次新对话，不需要从头说起，一个命令搞定。这就像每次看新医生都要从头讲病史，和直接递过去一份完整病历的区别。

第二层，理解你的意图。Vin 还有个 /today 命令，拉取日历、任务、iMessages 加上过去一周的日记，生成当日计划。但这不只是简单的日程整合。因为 AI 同时读了你的笔记，它知道你最近在思考什么。如果你的日历里全是社交活动，但笔记里写的全是技术研究，AI 会发现这个落差。

第三层，发现你自己都没注意到的模式。Vin 用 /trace 命令追踪了"使用 Obsidian"这个想法的演变。AI 从散落在不同文件里的笔记中，拼出了四个阶段：2024 年 12 月，Obsidian 完全不在他的工具链里。到 2026 年 1 月，进入了"爆发式构建期"。跨度 13 个月。他自己都没意识到这个想法已经酝酿了这么久。

这就是关系网的威力。单个文件是碎片，关系网才是记忆。

[SLIDE 4: checklist] (4:15 - 5:15)

那怎么判断你该不该用这套方案？看三个信号。

信号一：你每次开新对话都在复制粘贴同样的背景信息。说明你缺的是持久化的上下文，不是更好的提示词。

信号二：你有笔记习惯，但笔记之间没有连接。散落的文件再多，AI 也只能一个一个读。有了链接，AI 才能看到全貌。

信号三：你希望 AI 不只是执行指令，而是真正理解你在做什么、为什么做。这需要的不是更大的 Context Window，而是更结构化的上下文。

[SLIDE 5: summary] (5:15 - 6:00)

一句话总结：AI 的能力上限，取决于你喂给它的上下文质量。而 Obsidian 的关系网络，是目前最高效的上下文投喂方式。

你现在就可以做的一件事：下载 Obsidian，它是免费的。创建一个 Vault，把你最重要的三个项目各写一个 markdown 文件，然后用双括号把它们互相链接起来。就这么简单，你已经开始构建属于自己的知识图谱了。
