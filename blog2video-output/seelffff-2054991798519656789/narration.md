# 每月300刀，连一个 Agent 都建不出来？

## Hook

你刷了一整年 AI 课，Coursera、DataCamp、Udemy 的证书攒了一抽屉，让你从零写出一个 Agent，写不出来。这不是你不够聪明，是顺序错了。X 上有个 ID 叫 self.dll 的 AI/ML 工程师，自己烧过每月接近 300 美元的订阅费才看明白这件事。他写了一份 14 周的路线图，把过去一年我们这群人踩过的坑全部摊开了——而且全程零成本。我把这份路线图读完之后，最想跟你聊的不是省了多少钱，是它把"先学什么后学什么"这件事，掰得有多狠。

## 真正在造 AI 的公司，比卖 AI 课的公司更愿意免费教

先说一个反直觉的事实。今天你能拿到的最好的 AI 入门课，不在 Coursera Plus、不在 DataCamp，也不在那些 199 美元的 Udemy 大包里。它们在哪？在 Anthropic、在 OpenAI、在 Google 自己。

Anthropic 自己开了一个学院，叫 Anthropic Academy，16 门免费课，每门发证书。OpenAI 也开了 Academy，Google 那边是 AI Professional Certificate，7 个模块。IBM 的 Machine Learning 证书，开 Coursera 审计模式就免费。

self.dll 算了一笔账。他自己之前每个月烧 49 美元 Coursera Plus，再加 39 美元 DataCamp，外加 199 美元的 Udemy 课程包，加起来接近 300 美元。一年下来，证书攒得像宝可梦卡片，从零写一个东西出来——写不出来。

这件事的本质我想了很久。它的逻辑其实非常清楚：免费课对 Anthropic 来说，是生态投资，多一个人会用 Claude，他们就多一个潜在客户。但免费课对 DataCamp 来说，是把自己的核心商品送出去。所以激励是完全反过来的。真正在造 AI 的公司，比卖 AI 课的公司更愿意把训练材料免费给你。

## GitHub 上那几个 9 万星、4 万星的 repo，比你买的课更狠

除了三大公司的免费学院，self.dll 反复强调的第二件事，是 GitHub 上几个超大型的免费 repo。

最大的一个，microsoft 的 generative-ai-for-beginners，9 万 5 千颗星，21 节课。第二个，microsoft 的 ML-For-Beginners，4 万 5 千颗星，12 周课程。第三个，mlabonne 的 llm-course，4 万颗星，从线性代数一路讲到模型量化。

你想想这个数字。一个开源 repo 拿 9 万 5 千颗星，意味着它的口碑已经被几十万人验证过了。而你订阅的那个付费课，验证它的可能只有几十条评论。免费的东西不一定差，付费的东西也不一定好——这件事在 AI 教育领域今天已经反过来了。

## 真正的问题不是钱，是顺序

但读到这儿你可能会想，这些资源我也知道啊，我都收藏了，我就是没学进去。

self.dll 在这份路线图里给了一个特别重要的观察。他说，2026 年自学 AI 的人，绝大多数倒在同一个坑里——顺序错了。

他的路线图分七步。我快速念一下：第一步装环境，第二步 AI 基础概念，第三步机器学习数学基础，第四步深度学习从零手写神经网络，第五步 LLM 和 Prompt Engineering，第六步 Agent，第七步生产化和职业。

注意看这个顺序。机器学习数学基础在第三步，深度学习手写神经网络在第四步，而 LLM 和 Prompt Engineering——你最想直接跳过去学的那个——它在第五步。Agent 在第六步。

绝大多数自学 AI 的人，是反着来的。先去刷 Prompt Engineering 视频，因为看起来最酷；再去学 LangChain，因为听起来最值钱；最后再回头补数学，结果补不下去。

self.dll 把第一条铁律写得很硬，原话是：Don't skip ahead. 不要跳步。然后给了一个很扎心的解释——如果你跳过梯度直接学 LLM，你写出来的代码自己都看不懂，你只是在 copy-paste。

## 公司付 15 万美元的，是会 debug 模型的人，不是会调 API 的人

为什么顺序这么重要？路线图里有一句话我反复看了好几遍。

他说，机器学习基础是"会抄教程的人"和"会 debug 模型的人"之间的分水岭。公司愿意为后者付 15 万美元以上，不是为前者。

这句话我帮你翻译一下。今天你打开任何一个 AI 创业公司的招聘页，Junior AI Engineer 大概是 8 万到 12 万美元，Prompt 或 Agent Engineer 是 12 万到 18 万，AI Product Engineer 是 15 万到 25 万。这三档的差距在哪儿？不在你会不会调 Claude API——API 文档谁都能查。差距在模型出问题的时候，你能不能拆开看哪一层不对。

会调 API 的人，今天已经不稀缺了。稀缺的是看到一个模型输出乱七八糟，能立刻判断是数据问题、是过拟合、还是注意力机制设计的问题。这种判断力，只有你自己手写过一遍神经网络才会有。

## 第四步：Karpathy 的那七节课，是真正的分水岭

所以第四步是整份路线图的核心。Primary 资源只有一个名字——Andrej Karpathy，前 Tesla AI 总监，OpenAI 联合创始人。他在 YouTube 上有一个系列叫 nn-zero-to-hero，七节课。

这七节课的特点是，全程不用任何深度学习框架，纯 Python 加数学，从零手写神经网络。第六周你写 micrograd，自动微分引擎；第七周写 makemore，理解激活函数、批归一化、反向传播；第八周直接手写一个 GPT 加 tokenization。

路线图建议你这样做：一边在 Jupyter 里训练你那个一千万参数的玩具模型，一边在终端跑 ollama run llama3.2:3b。Ollama 是一个本地跑模型的工具，3b 是 30 亿参数的 Llama。

你会同时看到两件事。一边是你的玩具模型在生成乱码，一边是 30 亿参数的真实模型在写连贯句子。你会突然明白参数规模意味着什么——不是某个抽象数字，是你眼前两个窗口里输出质量的差距。

这个对照实验是这份路线图我最喜欢的设计。理论和实物同时摆在你面前，你不可能学不进去。

## Week 10 项目：给自己的笔记建一个 RAG

接下来才是 LLM 和 Prompt Engineering。Step 5 第十周有一个项目我特别想讲。

self.dll 让你做这件事：用 ChromaDB 或者 LanceDB——都是免费的本地向量数据库——给你前面九周写在 Obsidian 里的所有笔记建一个 RAG。建好之后你可以问它任何问题：我学过的 transformer 是什么？我对 backprop 还有什么不懂的？它会从你自己的笔记里把答案翻出来。

他原话挺幽默的，说你这是在给自己的"第二大脑"再建一个"第二大脑"。

但这个项目的位置很有意思——它放在第十周，不在第一周。网上一大堆"5 分钟做个 RAG"的教程会让人误以为 RAG 是 Day 1 玩具。这份路线图把它放在 LLM 架构、量化、评测之后才建，因为前面那些基础没打牢，你建出来的 RAG 是个黑盒——出问题完全不会修。这是顺序设计的另一个体现。

## Agent 和 MCP：2026 真正要会的接口层

第六步是 Agent。这是 2026 整个 AI 工程领域最热的位置。

self.dll 在这一步给了一个明确判断：MCP，Model Context Protocol，是 Anthropic 的开放标准，是 2026 Agent 工具接入的标准。他要求你学 Anthropic Academy 的两门 MCP 课——Introduction to MCP，再加 MCP Advanced Topics——亲手从零写一个 MCP server 和 client。

为什么 MCP 重要？因为 Agent 的本质就是给 LLM 装手脚。LLM 自己只能输出文字，但接上 MCP 之后，它可以读你的文件、查网页、发邮件、动数据库。MCP 就是那个统一的接口规范。没有它，每个 Agent 工具都要写一遍自己的桥接代码，重复劳动。

最终项目是这样的：一个 Agent，用 MCP 加 Claude，读你的 Obsidian 笔记，去网上查你正在学的话题有没有更新，每天给你的 Telegram 发一份总结。这个 demo 一出来，你的 GitHub 就有了一个能拿出来跟人讲的真东西。

## 14 周不便宜，时间是真实的代价

但路线图我也要给你讲讲它的代价。

14 周看起来很短，但每一步都有 Checkpoint。原话是：做不到就回去。这不是建议，是规则。每周大概需要 10 到 15 小时的投入，14 周加起来差不多 140 到 210 小时。

这是一份免费的路线图，但"免费"只对愿意把这 200 小时摆上来的人成立。对刷视频拿证书的人，它跟之前那个 300 美元一个月的订阅是一样的——什么都建不出来。

而且学完不是终点。路线图最后给的 Maintenance Mode 还要你每周再投 1 小时：周一看 Anthropic、OpenAI、Google 的发布记录，周三读一篇 paper 摘要，周五看一个新工具视频，每月做一个新的小项目。AI 这个领域 14 周学不完，14 周学到的是"学会持续学习"。

## Synthesis：顺序就是这份路线图最贵的部分

读完整份路线图，我觉得它真正的价值不在那些免费链接——链接谁都能搜得到——而在顺序本身。

self.dll 自己烧了 6 个月、300 美元一个月的订阅，才看明白这件事：先学装环境，再学概念，再学 ML 数学，再手写神经网络，再调 API 学 Prompt，再做 Agent，最后部署。这个顺序，每一步都有理由。

倒过来呢？倒过来你就是这一年 AI 圈最普遍的现象——会用十种 Prompt 技巧，会调七种 API，但模型出问题没有任何手感，写代码全靠 copy-paste，简历上挂着十几个证书，去面试拿不到 offer。

学 AI 在 2026 年最贵的不是订阅费，是把第五步当成第一步的代价。

## Closing

最后给你一个特别简单的可执行建议。今晚 60 分钟，做三件事：装 Obsidian，建好那个 AI-Learning 文件夹结构；注册 Anthropic Academy，把第一门 AI Fluency 的第一个模块看完，写下第一篇笔记；再去 GitHub fork microsoft 的 generative-ai-for-beginners，打开 Lesson 1 读完。

self.dll 那篇文章结尾有一句话写得特别狠。他说，2026 年真正学到 AI 的，不是收藏了 50 篇文章的人，是今晚就打开终端开始的人。

AI 世界很吵，精读一篇，胜过刷一百条。我们下期再见。
