// 坚持 vs 固执
简单时,你分不清
一条路可走 → 两种人都说"不放弃"
流行文化混为一谈 · 默认问题简单
可一旦复杂,差别就现形
// 把决策想象成一棵树
高
大方向:死死执着
坚持的人,树越高越不肯松手
低
小枝节:说改就改
坚持的人,低处随时调整
固
固执的人:不分高低
把"别放弃"喷满整棵树,连末梢都死抓不放
有意思的是，在最简单的情况下，你根本分不出这两种人。
因为当一个问题只有一条路可走，唯一的选择就是放弃还是不放弃，两种人都会说“不放弃"。
这也是为什么流行文化总把它们混为一谈——它默认问题都很简单。
可问题一复杂，差别就现形了。
把决策想象成一棵树，坚持的人对树高处那些大方向执着得多，对低处那些小枝节，说改就改；而固执的人，是把“别放弃"三个字，
无差别地喷洒到整棵树上，连最细的末梢都死抓不放。
