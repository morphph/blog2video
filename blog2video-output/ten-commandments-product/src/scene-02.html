先从最普遍的一个陷阱说起。
过去几年，模型能力跳得太快了。
很多工程师和研究员开始有一种感觉：技术突破本身就证明了价值，就像 ChatGPT 把研究成果直接变成了产品。
但那是一个神话。
ChatGPT 底层的模型，在产品发布之前就存在很久了。
真正让它成为现象级产品的，是那个最普通的聊天框。
而且就算这样，Sam Altman 自己说，早期留存"惨不忍睹"。
他们也犯过同样的错。
Minecraft Agent 项目里，他们做到了一件很酷的事：多个 Agent 协作，能一起造出三百多种物品，还能建钻石镐。
登上了 X 和 Hacker News，获得了很多关注。
但他们始终没搞清楚一件事：这个能力，解决了哪个真实玩家的什么真实问题？
关注不是需求。
技术壮举不是产品。
中间那步翻译工作——搞清楚是谁的问题、他们怎么用——才是全部的工作，不是注脚。
