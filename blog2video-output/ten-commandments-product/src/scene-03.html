// 陷阱二 · 同一个错，犯了三次
用户标签 ≠ 知道用户
01
Minecraft Agent
说是「Minecraft 玩家」
实为：建造 / PvP / 社交 — 三个不同的产品
02
Fairies 桌面 Agent
说是「白领工作者」
实为：他们希望白领是用户，白领不这么看自己
03
Shortcut Excel AI
说是「所有 Excel 用户」
实为：金融领域 · 高标准 · 高质量工作者
$ insight
日志告诉你用户做了什么
你真正饿着的是「为什么」
说到「用户是谁」，他们在三个产品里犯了同一个错，犯了三次。
做 Minecraft Agent 的时候，他们说用户是 Minecraft 玩家。
后来仔细一看：有人玩这个游戏是为了建造，有人是为了 PvP 对战，有人就是想跟朋友在一起。
三种人要的是三个不同的产品。
做通用桌面 Agent Fairies 的时候，他们说用户是「白领工作者」。
更诚实的说法是：他们希望白领是用户，但白领根本不这么看自己。
做 Excel Agent Shortcut 的时候，他们说「所有 Excel 用户」。
后来才慢慢找到那个真正有价值的子集：金融领域里，做高标准高质量工作的人。
每次都是同一个移动：把模糊的标签当作「知道了用户」。
文章里有一句话我觉得说到位了：日志告诉你用户做了什么，但你真正饿着的是「为什么」。
早期最危险的逃避，恰恰是那些最「科学」的东西——数据分析、漏斗报告——因为它们看起来像进展，但都是在重建用户行为的脑补版本。
真正的办法只有一个：去坐在他们旁边，看他们在自己的环境里怎么用。
