// 代码 vs 媒体
媒体,比代码更重要
Code
代码
价值是客观的

→ 容易被商品化,谁都能复制
Media
媒体 / 内容
价值是主观的
每个读者,解读都不一样
→ 没有唯一写法,只有你能写
前面那张图的答案:App 越来越多,使用却在下降
因为它们没有分发能力,不懂媒体、不懂内容
但在代码和媒体之间,我认为,媒体比代码更重要。
媒体,说的就是内容。
发一次就能被成千上万人看到的帖子、视频、播客或文字。
为什么是媒体?
因为内容的价值是主观的。
每一个读者,读你的每一句话,解读都不一样。
换句话说,没有唯一正确的写法。
而代码的价值,相对是客观的。
你怎么写不重要,只要它能跑出你要的结果就行。
所以代码很容易被商品化,谁都能复制。
这也正是前面那张图的答案——
App 越来越多,下载和使用却在下降。
为什么?
因为它们没有分发能力。
它们不懂媒体,不懂内容。
它们没法让人用起来,更没法让人在乎到愿意付钱。
