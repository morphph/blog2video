Inside the Kernel

帧吸附:杀掉 0.5 秒漂移 // the one snippet worth reading

逐场景渲染时,每个 clip 被渲成 ceil(dur×30) 帧 —— 每段多 0~1 帧,累加到片尾比口播慢约半秒。修法:把边界吸到帧,让每段 dur 都是 1/30 的整数倍。

// build-scenes-data.mjs · 帧吸附边界
// 连续边界 = 各场景 start + contentEnd + (contentEnd + CTA)
const boundsSec   = [...slides.map(s => s.start), contentEnd, contentEnd + 5];
const boundsFrame = boundsSec.map(t => Math.round(t * 30)); // ← 吸到帧

const startSnap = i => boundsFrame[i] / 30;
const durSnap   = i => (boundsFrame[i+1] - boundsFrame[i]) / 30;
// 每段 dur 都是 1/30 整数倍 → ceil(dur*30) 不再膨胀 → 零累积漂移
  • 字幕按未吸附 slide 边界归位(= slide 成员关系),按吸附 start 重定基 —— 与音频对齐到 ≤ 半帧。
  • 算法复刻自老 render-image-video.mjs 的对齐逻辑,只多加一步取整。

Render & Compose

逐场景,绝不渲整片 // per-scene, never the whole film

>240s 的合成会让 8GB 机器 OOM。每段渲成静音 clip,无损 concat,最后一次性混音 —— 视频是主轨,音频放完转静音,保留 CTA 尾卡。

step 1 · 串行
hyperframes render
逐场景渲静音 clip,跳过已渲(断点续渲)。NODE_OPTIONS=--max-old-space-size=5120
step 2 · 无损
concat
按序拼成静音整片(-c copy),帧对帧无损。637+1447 帧实测精确相加。
step 3 · 一次
mux audio
raw 音频,零响度处理。不 -shortest → 保留 CTA 静音尾卡。
→ video_N.mp4 · h264 + aac

Gotchas · 铁律

踩坑换来的不可推翻决策 // hard-won, do not override

这些不是偏好,是 Phase 1 用 OOM、漂移、豆腐块换来的约束。改它们之前先看这一节。

✕ 不渲整片
>240s 合成在 8GB 必 OOM。逐场景静音 clip → concat → 一次混音。串行渲,并发叠内存。
✕ 不动音频响度
MiniMax 输出直接用。绝不 loudnorm / boost / 后处理 —— CLAUDE.md NEVER 条款。
✕ 不忘帧吸附
场景边界必须 round(t×30),否则逐 clip 的 ceil 取整累加成片尾 ~0.5s 漂移。
✕ 不用错 node
必须 node v22.x + 5120MB 堆。否则渲染 / 快照 OOM。Apple Silicon 走 brew node@22。
✕ 不丢签名色
酸性绿 #CCFF4D 每一帧在场;除它之外任意一帧最多再一种辅助色。
✕ 不放 emoji
无 emoji 字体 → 渲成豆腐块。源里的 emoji 一律删或换 mono 符号 → › ●。
✕ 不先拆后写
写在先,拆在后。叙述质量不被分集决策污染;时长是结果,不是输入。
✕ 不漏投递排除
只传 6 个交付件;不能用 --exclude=*.mp4(会误删 video_N.mp4),靠排除 clips/ renders/ 目录。
