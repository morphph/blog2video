这是全片最重要的伏笔,马上展开。
审查通过,循环通过 MCP 连接器自动开 PR、更新工单。
MCP 是智能体跟真实世界对接的协议。
Claude Code 和 Codex 都用它,两边概念一一对应,连接器基本互通。
它处理不了的问题呢?
落进一个收件箱,等人来看。
一天结束,状态文件记下今天试了什么、过了什么、剩下什么。
明天早上,循环从今天停下的地方继续。
这就是状态文件的意义:智能体每次运行结束都会失忆,状态文件是循环唯一的记忆。
没有它,每天都从零开始。
