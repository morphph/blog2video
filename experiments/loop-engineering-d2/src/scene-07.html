还记得早上那个自动醒来的定时任务吗?
那是第一个模块,Automation,自动化。
它解决的失败模式最朴素:没有触发器,循环就得靠你记得去启动——那就不叫循环了。
Codex 那边有个 Automations 面板,配好项目、提示词和频率就行。
没发现问题的运行,还会自动归档,不来烦你。
Claude Code 这边是另一套:/loop 让任务按节奏反复跑,Hooks 在关键节点挂上命令。
另外有个 /goal,是我最喜欢的设计,先按下不表,案例里讲。
想让循环在你合上笔记本之后继续转?
接上 GitHub Actions 这类 CI 设施就行。
